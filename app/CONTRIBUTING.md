# Contributing

Thank you for improving POWERVERSE.

1. Create a focused branch from the latest default branch.
2. Run `bun install` and `bun run dev`.
3. Keep examples accurate, concise, and supported by current Microsoft documentation.
4. Test navigation, search, playground output, keyboard use, and mobile layouts.
5. Do not add secrets, analytics, trackers, or remote executable scripts.
6. Open a pull request explaining the user-facing change and how it was tested.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
